## 🎯 Objetivo
Solicitar permisos de ubicación, obtener coordenadas del dispositivo y representarlas en una interfaz preparada para mapas.

## 🛠️ Requisitos
- Flutter SDK 3.47.2+
- Dart 3.13.2+
- Visual Studio Code
- Paquetes: geolocator, url_launcher
- Permisos de ubicación en Android

## 📦 Instalación

## 🚀 Ejecución

